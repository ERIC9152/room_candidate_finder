# 同房判定評估標準（整批配對）

用途：評估模型「從一整批全景中找出同一間房的全景、並分成房間」的能力。可直接套用到新資料集。 英文版：[EVALUATION_STANDARD.md](EVALUATION_STANDARD.md)。
最後更新：2026-10-23（取代先前只計已分組 pano 的「群組成員制」，舊版說明見文末附錄）。

## Ground truth

- 每棟房子（task）的所有室內全景構成一個「房間分割」。
- 人工把同一間房的全景編成房間群組（至少 2 張）；沒有被編進任何群組的全景，視為只有自己一張的房間。
- 建議流程：先以人工群組為 GT 計算一次；再把「任一模型判同房、但 GT 為不同房」的配對做盲審（不顯示模型來源、混入已知答案的對照組），用審查結果修正 GT 後重算。報告需同時列出審查前後的數字與對照組一致率。

## 第一層：同房判定（評估判定機制本身）

- 範圍：同一棟、同一樓層（含樓層未知）的**所有**無序全景配對，不事先篩選。
- 每一對：模型判「同房」或「不同房」，與 GT 比較。
  - Precision = 判同房且 GT 同房 / 判同房
  - Recall = 判同房且 GT 同房 / GT 同房
  - F1 = 2PR / (P + R)
- 另外報告「困難負例誤判率」：導覽 hotspot 直接相連、但 GT 不同房的配對（多為隔門可見的相鄰房間）被判同房的比例。

## 第二層：分群（評估分成房間的能力）

- 把模型判同房的配對取連通分量，每個分量是一個預測房間。
- 分群（配對）：Precision = 被分在同一預測房間、且 GT 同房的配對 / 被分在同一預測房間的配對；Recall = 被分在同一預測房間的 GT 同房配對 / GT 同房配對。
- 房間：Precision = 與某個 GT 房間完全相同的預測房間（≥2 張）/ 預測房間數；Recall = 被完全還原的 GT 房間（≥2 張）/ GT 房間數。

## 報告規則

1. 每個模型的每個操作點（規則或門檻）各列一行 P / R / F1 與 TP、FP、FN。
2. 模型若只在抽樣配對上執行，以 1/抽樣機率加權並註明為推估值。
3. 門檻若用同一份資料選出，另外報告「留一棟房子交叉驗證」的結果。
4. 列出 GT 的群組數、全景數、配對數、標註檔版本，以及盲審規模與對照組一致率。

## 附錄：群組成員制（已停用）

只計「兩張都屬於人工群組」的配對。它丟掉了絕大多數負例（本資料集只剩 667 對，整批約 7,500 對），尤其是隔門相鄰的房間，會讓 precision 嚴重高估（例如 floor ≥750 由 0.27 被算成 0.80）。程式與結果保留在 `scripts/group_standard.py`、`work/group_standard_*.json`，僅供對照。
